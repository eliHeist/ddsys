{% comment %} The one dialog for every "ask a few questions, then POST" action. Open it with $dispatch('open-dialog', {title, message, url, submit, danger, target, swap, fields: [{name, label, type, value, required, options}]}) (see actionDialog in core/_scripts.html). It is built from data, so it is not a (which is one dialog per trigger); it uses the kit's controls and the dialog's look. Alpine bindings on the components use `::`. {% endcomment %}
